# Mục lục tài liệu (V15.0.0-rc.0)

| Nhóm | File | Mục đích |
|---|---|---|
| (gốc docs) | `PROJECT_STATUS.md` | Trạng thái hiện hành, bằng chứng, mức sẵn sàng |
| | `NEXT_TASKS.md` | Việc cần làm tiếp theo thứ tự ưu tiên |
| | `WORK_LOG.md` | Nhật ký các phiên làm việc (lịch sử, thêm vào cuối) |
| | `CLEANUP_REPORT.md`, `CLEANUP_CHANGELOG.md` | Báo cáo và nhật ký đợt dọn dẹp 14/11/2026 |
| | `FILE_INVENTORY.md` | Kiểm kê từng file và trạng thái |
| | `ARCHIVE_INDEX.md` | Chỉ mục tài liệu đã lưu trữ |
| `guides/` | `LOCAL_DEVELOPMENT.md` | Cài đặt, chạy local, Emulator, test |
| | `DEPLOYMENT_AND_HANDOVER.md` | Triển khai Firebase của người mua, bàn giao, sao lưu/khôi phục |
| `technical/` | `ARCHITECTURE.md` | Kiến trúc theo source thực tế |
| | `API_DOCUMENTATION.md` | Cloud Functions (sinh tự động bằng `npm run docs:api`) |
| | `SECURITY_AUDIT.md` | Rules, ghi từ client, bảo mật phụ thuộc |
| | `PERFORMANCE_AND_COST.md` | Số đo tĩnh, điểm nghẽn, yếu tố chi phí |

| | `KNOWN_ISSUES.md` | Vấn đề đã biết (hiện hành) |
| | `STRUCTURE_REPORT.md` | Phân tích cấu trúc (sinh bằng `npm run docs:structure`) |
| `commercial/` | `PRODUCT_AND_FEATURES.md` | Mô tả sản phẩm và ma trận tính năng |
| | `READINESS_AND_ROADMAP.md` | Mức sẵn sàng, due diligence, lộ trình |
| `legal/` | `LICENSE_AND_ASSETS.md` | Bản quyền, tài nguyên bên thứ ba (bản nháp, chưa xác minh) |
| `archive/` | xem `ARCHIVE_INDEX.md` | Tài liệu V11–V14 và add-on cũ, chỉ để tham khảo |

Các file gộp (`PRODUCT_AND_FEATURES`, `READINESS_AND_ROADMAP`, `DEPLOYMENT_AND_HANDOVER`, `LOCAL_DEVELOPMENT`, `LICENSE_AND_ASSETS`, `PERFORMANCE_AND_COST`, `SECURITY_AUDIT`) chứa nhiều mục; nguồn gốc từng mục ghi ở tiêu đề mục.
